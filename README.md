# 🕌 Cuma Mesajları — Haftalık Dini Mesaj & Paylaşım

Her Cuma için güzel dini mesajlar, dualar ve Cuma suresini bir araya getiren; mesajları kolayca paylaşabileceğiniz bir Android uygulamasıdır.

## ✨ Özellikler

- 📩 Hazır Cuma mesajları koleksiyonu
- 🔀 Rastgele mesaj seçimi
- 📤 WhatsApp, SMS ve diğer uygulamalarla paylaşım
- 🕌 Cuma Suresi metni
- 📖 Dini dualar
- 💾 Favorilere kaydetme
- 📴 Çevrimdışı çalışma

## 🛠️ Teknolojiler

| Katman | Teknoloji |
|--------|-----------|
| Platform | Native Android |
| Dil | Kotlin / Java |
| Build | Gradle |
| Min SDK | Android 21+ |

## 📋 Gereksinimler

- Android Studio (Arctic Fox veya üzeri)
- JDK 17+
- Android SDK 21+

## 🚀 Kurulum

```bash
# Android Studio ile aç
# File > Open > cuma mesajları klasörü

# Gradle sync yap (otomatik)
# Run > Run 'app'
```

### APK Derleme
```bash
# Android Studio Terminal'de:
./gradlew assembleRelease
```
